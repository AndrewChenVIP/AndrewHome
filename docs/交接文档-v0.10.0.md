## 1. 项目是什么

万道自研的 ComfyUI 启动器（Windows，Python 3.11 + PyQt5）：**只做编排器，不分叉内核**——
拼参数、起进程、管配置、管插件/内核/模型库，一切挂 ComfyUI 生态既有扩展点。
GUI 与 CLI 同体，退出码与单行 JSON 是对外契约。万道生态定位：本地 ComfyUI 的统一入口 +
出图归档进 NAS 作品库的通道。对标分析对象为 Mie 启动器（其源码留存于
`05Agent工具库\02开源工具\ComfyUI-Mie-Package-Launcher`），本项目从零重写、未复用其代码。

## 4. 架构与技术决策记录（新 Agent 最容易踩的坑都在这）

| 决策 | 理由与注意 |
|---|---|
| 只做编排器，不分叉内核 | 一切挂官方扩展点（extra_model_paths.yaml/cm-cli/git//system_stats）；内核升级永不在启动器侧冲突 |
| AppContext 显式协议 | GUI/CLI 同一条构造路径；服务函数只收入参——Mie 的 HeadlessAppContext 手工镜像 40+ 属性漂移是前车之鉴，别再造替身 |
| pidfile 带 create_time 身份校验 | 机器重启 PID 复用时按"创建时刻±2s"判死；判活必须双验（PID 存在+时刻吻合） |
| 杀进程定点单次验尸 | 优雅→验尸→强杀一次→验尸；绝不按端口扫射、绝不重复补刀、绝不静默提权（Mie 的 UAC 误弹事故源）；只杀 pidfile 定点实例，外部实例绝不碰 |
| **端口真相原则** | status 的 running 看 /system_stats 是否应答，pidfile 只回答"是不是我们起的"；外部占用时 start 拒绝（退2+external:true）——真机事故复盘产物，回归测试 test_external_instance_occupying_port 守着 |
| 单一实现铁律 | pidfile/pip 封装（pipx）/proc 子进程/旗标映射各只有一份正本；改逻辑先找正本，别开副本 |
| CUDA 冻结保护 | pipx.FROZEN_PKGS（torch/torchvision/torchaudio/triton）在一切依赖操作前剔除——本机 torch cu12x 手工调校，pip 盲装会冲掉 CUDA 栈 |
| core 层禁 PyQt5 + 架构守卫测试 | tests/test_arch_guard.py 用 AST 扫描锁死（禁 Qt 混入、禁裸 except:pass）；新增铁律先加守卫再写码 |
| 测试端口 18999 | 单测避让真机 8188（老板实例常驻）；否则 status 类断言会被真环境打脸 |
| onedir 而非 onefile + 体积裁剪 | Mie 113MB onefile 启动解压慢；opengl32sw/QtQuick/翻译全裁 → 64MB；打包入口是 run.py（不是 __main__.py，相对导入会炸） |
| 冻结模式配置锚点跟 exe 走 | sys.frozen 时配置目录 = exe 同级 launchpad/；便携原则，源码模式跟项目根 |
| 主题 token 化 | 颜色只有 token 一份、QSS 生成唯一；v0.6 三稿重做（视觉评审 8.5/10）全靠这层基础 |
| sidecar 唯一真源渲染 yaml | model_libs.json 原子写 → extra_model_paths.yaml 是渲染产物（先备份）；直接改 yaml 会被下次 apply 冲掉 |
| 归档只增不删 | 同名同大小跳过、同名异大小改名续位、日期分夹；水位（last_archive_at）只在拷贝成功时推进 |
| offscreen 冒烟纪律 | 别在冒烟里触发 QMessageBox 模态（永久阻塞）；缩略图管道要给足 8 秒；nav 行号先打 label 再导航 |

## 5. 开发循环与发布流程

**日常**：改码 → `pytest`（必须全绿）→ GUI offscreen 冒烟（`QT_QPA_PLATFORM=offscreen`，
别触发模态框）→ 提交（身份：陈守一 shouyi@wandao.local）→ `git push origin main`
（直连间歇重置，失败间隔 40s 重试，历史上从未超过 5 次）。

**发版**：版本号同步三处（`wandao_launchpad/__init__.py`、`pyproject.toml`、README 提及处）
→ `python scripts/build.py` → `cp launchpad/config.json dist/WandaoLaunchpad/launchpad/`
→ 冻结版冒烟（exe `--json doctor --quick` + status）→ 源码 zip 用 `git archive HEAD`
→ 双 zip 入 NAS 任务夹交付物。

**CI/签名**：workflow 已备（windows-latest，cmd 重定向 + artifact 取证），因 GitHub 账号
billing 锁未跑；解锁后推任意提交即验证。数字签名：无（便携 zip 分发，未做代码签名，
如需签名属待老板决策事项）。
